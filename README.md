# My-okww

自用的鸣潮自动化工具 [OKWW](https://github.com/ok-oldking/ok-wuthering-waves) 配队轴仓库。

这里**不放 OKWW 本体**，只放自己研究出来的固定配队输出轴，以及开发这些轴时读过的参考资料。
一条轴的交付物 = 一组角色脚本 + 说明文档 + 一个可直接导入 OKWW 的 zip。

## 当前这条轴

**弗卜维（卜灵 / 弗洛洛 / 维里奈）固定启动 + 循环轴**，当前版本 `1.2.0`。

- 只在检测到这三人的队伍时接管，其他队伍走各自原本的逻辑。
- 动作顺序来自目标作者的 24 FPS 手操录像，时序参数按实机反复校正。
- F 键「谐度破坏·音感仪」暂不加入。
- 详情见 [`弗卜维施法顺序v1.2.0/Agent.md`](弗卜维施法顺序v1.2.0/Agent.md)，
  时序依据见 [`TIMING.md`](弗卜维施法顺序v1.2.0/TIMING.md)。

### 怎么用

1. 把 `弗卜维施法顺序v1.2.0/` 里的 `Douling.py`、`Phrolova.py`、`Verina.py`
   覆盖到 OKWW 的 `src/char/`（先备份原文件）。
2. 重启 OKWW，让导入的角色类和队伍代码缓存刷新。
3. 队伍里放恰好这三个人，开始自动战斗。

详细步骤和运行时检查清单见交付物内的 `Agent.md`。
