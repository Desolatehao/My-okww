# DPV 轴 1.0.6 进展

## 本版本范围

这是一个独立版本快照，基于卜灵、弗洛洛、维里奈固定三人轴。F 键“谐度破坏·音感仪”暂不加入。

本版本包含：

- 目标视频的 24 FPS 手动时间线：见 `MANUAL_TIMELINE_24FPS.md`。
- 当前三名角色脚本及角色资料。
- 按手动时间线做的时序调整。
- 卜灵卦象不足和重击被打断的保护性处理。
- 卜灵 phase 0 的双 A 延奏窗口、phase 3 的卦象生成与双重击衔接。
- 弗洛洛闪避期间预输入强化 A 的处理。
- 维里奈 phase 6 末尾双 A 的延奏窗口。
- 维里奈 phase 13 不可用技能的短等待处理。

## 代码变更

### 卜灵

- phase 0 改为第二次 A 延后约 `0.30 s`，总留场窗口约 `0.60 s` 后切人。
- phase 3 改为 `E -> 4A -> 跳 -> 空中 A -> Z -> Z -> R`；地面 A 间隔约 `0.20 s`。
- phase 3 两个 Z 使用约 `0.75 s` 长按；两次 Z 之间等待 `0.20 s`，第二个 Z 后等待 `0.35 s` 再释放 R。
- phase 9 的两个 Z 前增加第二次空中 A，并在两个 Z 之间补充四段地面 A。
- `_heavy_attack_hold()` 在三次尝试都被浮空打断时返回失败。
- `_axis_heavy()` 记录被打断的 phase，并让持久 step 逻辑负责重试。
- 其它卜灵重击仍使用参考实现的 `2.50 s` 长按值；phase 3 使用独立实机时长。

### 弗洛洛

- 增加 `_axis_dodge_enhanced()`，在闪避动画期间预输入强化 A。
- 普通闪避强化 A 的等待窗口调整为 `0.25 s`。
- `3A-闪-A-闪` 链内使用 `0.55 s` 的独立衔接窗口。
- phase 2 的 Q 改为短尾部衔接，不再额外固定等待 2 秒。
- 弗洛洛 Z 的当前长按值调整为 `1.33 s`，对应记录中的 `00:00:42:02 -> 00:00:43:10`。
- unavailable action 的等待上限调整为 `1.5 s`。

### 维里奈

- phase 6 的最后 `AA` 改为第二次 A 延后约 `0.30 s`，总窗口约 `0.80 s` 后再切换。
- phase 13 unavailable action 的等待上限调整为 `1.0 s`，减少末尾长时间停留。

## 当前证据和限制

- 三个脚本已通过 Python 语法编译。
- `git diff --check` 已通过。
- 已通过实机测试确认：卜灵 phase 0 能稳定完成第二次 A；phase 3 前置卦象可达到 `艮、震、震、震`，两个 Z 均可触发且 R 不再打断第二个 Z；维里奈 phase 6 末尾 AA 可完成两次 A 后切人。
- 卜灵的卦象没有现成的结构化读取接口；当前 phase 9 的额外空中 A 是基于角色资料的保守修复。
- 视频为 24 FPS、无键鼠叠加层，无法确认所有预输入的确切按键帧。
- 当前版本没有加入 F 键，也没有改变通用 `src/char` 运行副本。

## 下一次实机验证

```text

dpv axis phase=3 step=...
dpv axis heavy interrupted phase=...

dpv axis phase=9 step=...
```

需要确认：

2. phase 7 和 phase 14 的 `3A-闪-A-闪` 是否丢失动作。
