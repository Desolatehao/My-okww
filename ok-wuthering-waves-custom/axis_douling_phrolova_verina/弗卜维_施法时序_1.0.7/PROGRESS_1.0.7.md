# DPV 轴 1.0.7 进展

基于 1.0.6，仅修正弗洛洛 phase 2 的动作衔接窗口；通用框架及其它 phase 不变。

## 代码变更

- phase 2 保持 `aa q A e A z`，`q` 按本地键位约定调用声骸。
- Q 后首个强化 A 增加 `0.90 s` 衔接等待。
- phase 2 两次强化 A 窗口设为 `0.55 s`。
- phase 2 Z 长按由 `0.10 s` 增至 `0.25 s`；为第二次强化 A 后留出发送 Z 的余量，仍在输入完成后切到卜灵。
- phase 7 的 `3a` 合并为可调总时长 `1.30 s`，期间每 `0.15 s` 发送一次平 A；总时长结束后直接闪避打断并接强化 A。
- phase 5 的 `aa` 改为 `2.05 s` 总持续窗口，期间每 `0.15 s` 输入一次平 A；窗口结束后再释放 Q。
- phase 7 尾段增加专用衔接：Q 后 `0.10 s` 发送强化 A，Z 后等待 `0.30 s` 再发送 R。
