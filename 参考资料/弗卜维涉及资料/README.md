`参考资料/` 按轴分文件夹：以后每写一条新轴，就在 `参考资料/` 下并排新建一个 `<轴名>涉及资料/`。

这条轴的时序不是凭空估的。三个角色各有一份参考包，另外还有一张连招图。
这些包**不是本轴的交付物**，是本轴开发时读过的原始资料，删掉就没有对照依据了。

## 使用注意

- 这三个轴包都是**别人写给别的队伍**的实现，本轴只借用其中的时间数值和动作顺序，不继承它们的队伍逻辑。
- 卜灵那份是「实现等待值」，弗洛洛那份是「逐帧派生点」，两者可靠性不同，在 `TIMING.md` 里已经分开标注；
  不要把它们混成同一类证据。
- `TIMING.md` 的「证据来源」一节直接引用上面三个路径，已经指向 `参考资料/弗卜维涉及资料/`。
  1.0.6 – 1.1.1 的历史快照里写的还是移动前的根目录路径，那些是冻结记录，不再回改。
- 这些资料原先散落在仓库根目录，2026-09-10 先收进 `参考资料/`，再按轴归到 `弗卜维涉及资料/`。
